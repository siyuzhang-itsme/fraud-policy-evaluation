What changes when labels are cleaned?

Unsafe shortcut

“Every submitted claim or commercial dispute is a fraud positive.” This mixes unrelated complaint reasons with unauthorized intent.

Evidence-based treatment

Exclude non-fraud reasons, preserve unresolved classifications and use independently supported intent where available. Document which policy layer was actually involved.

Scope: This runnable example distinguishes claim reasons and supported intent. A more advanced temporal inferred-label rule (using only in-scope fraud-policy declines near a confirmed event) is a documented future extension, not a separate inference engine or measured result in this synthetic example.

RETAIN

Maintain existing scope when tested alternatives fail protective criteria.

REFINE

Narrow the tested rule when comparative evidence supports the trade-off.

RETIRE

Remove the tested layer only when downstream outcomes and limits justify it.

INVESTIGATE NEW RULE

Formulate and test a new hypothesis. Its benefit is not estimated here.

DEFER

Keep collecting evidence while classification or uncertainty remains unresolved.

Methodological scope: a preliminary, nonproprietary synthetic decision framework. Inputs and calculations are reproducible from the shipped fictional CSVs using python code/build_feedback_loop.py. The pilot has complete independent audit labels and three randomized synthetic alternatives; neither feature is asserted to be available in a real institution's historical two-arm test.

Boundary: the assumed 1% interchange is illustrative, not actual booked issuer revenue; approvals are treated as potential settling volume only for this thought experiment. This is not a financial institution's production dashboard; it does not train a model, prove third-party adoption, or measure real avoided loss. Integration of monitoring, label review, dispute/recovery feedback and policy governance is a methodological demonstration. Substantive applicant review and release permission are pending.
