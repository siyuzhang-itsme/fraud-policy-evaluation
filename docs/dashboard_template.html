Governance Decision · What should we do next?

Only after reviewing fraud capture, customer treatment, follow-up maturity and statistical uncertainty do we decide which option is supported.

RETAINKeep the existing broad rule when alternatives fail the protection and customer-impact criteria.
REFINEImplement the tested narrower condition if the evidence supports a safer, more selective rule.
RETIRERemove this tested rule only if downstream checks and evidence support the change.
